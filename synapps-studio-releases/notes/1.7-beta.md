# Notes de version `1.7` beta

Cette version beta s'appuie sur la version stable `1.7.2` : voir ses [notes de version](./1.7.md).
Seules les évolutions de la beta sont décrites ici.

## Révisions

> 1.7.3-beta - 2026-10-08T14:00:00

- Ajout d'un additionnel de type _Style_.
- Ajout de l'option copier / coller pour les dossiers.
- Ajout d'un menu contextuel pour sélectionner un acteur sous le curseur.
- Désactivation du squelette de la modale lorsqu'elle n'est pas affichée.
- Correction d'un souci lors de l'ajout d'un _leadActor_.
- Correction d'un souci avec les clés d'acteurs lors d'un copier / coller.

> 1.7.3-beta - 2026-08-18T14:00:00

- Ajout de la possibilité de plier / déplier tous les dossiers de scènes dans l'explorateur de scènes.

> 1.7.3-beta - 2026-08-12T09:00:00

- Correction d'un soucis entre la multi-sélection et le designer de style

> 1.7.3-beta - 2026-08-10T12:00:00

- Multisélection mise à jour pour indiquer les acteurs sélectionnés dans la liste des acteurs de la scène.

> 1.7.3-beta - 2026-08-07T16:00:00

- Runtime version 2.9.3 supportée
- Mutliselection des acteurs dans une toile pour les manipuler simultanément (déplacement, disposition)

## Synapps Runtime version 2.9.3

- Support de la version `2.9.3` de Synapps Runtime, disponible dans la version de REDY `17.0.0`.

- Ajout de l'acteur technique _Module Adiabatique_.
- Ajout des acteur de _Barre de Navigation_ .
- Correction de l'acteur _Tuyaux_ et sa représentation _Flèche_ qui n'avait pas de taille.
- Ajout de la propriété _Entête?_ sur l'acteur _Groupe de navigation_ pour permettre de définir si le groupe est un entête ou non.
- Correction de la tooltip de l'acteur _Ternaire_ qui n'était pas prise en compte.

## Nouveautés

### Multisélection des acteurs

Il est maintenant possible de sélectionner plusieurs acteurs dans une toile pour les manipuler simultanément (déplacement, disposition). Les acteurs sélectionnés sont également indiqués dans la liste des acteurs de la scène.

![SynApps](../../assets/concepts/actor/multiselection.gif)

Les contrôles et les actions disponibles sont détaillés dans la [documentation de la multisélection](../../concepts/multi-selection.md).

### Menu contextuel de sélection d'acteur

Un clic droit dans la prévisualisation d'une scène ouvre un menu contextuel listant les acteurs situés sous le curseur. Il permet de sélectionner facilement un acteur recouvert par un autre.

![SynApps](../../assets/concepts/actor/context-menu-selection.gif)

Le fonctionnement est détaillé dans la [documentation de la sélection contextuelle](../../concepts/context-selection.md).

### Explorateur de scènes

- Ajout de la possibilité de plier / déplier tous les dossiers de scènes.
- Ajout de l'option copier / coller pour les dossiers.

### Additionnel de type _Style_

Ajout d'un additionnel de type _Style_.

### Squelette de la modale

Le squelette de la modale est désactivé lorsqu'elle n'est pas affichée.

## Corrections

- Correction d'un souci lors de l'ajout d'un _leadActor_.

### Copier / coller d'acteurs
