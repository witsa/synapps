# Variable WOS

Objet qui représente une *variable WOS* d'un REDY : c'est ce qu'un [fournisseur de variable]({{ site.baseurl }}/concepts/actor-types/redy/wos-variable-source.html) place dans sa donnée (`data`) quand aucun champ n'est choisi, et ce que renvoie le magasin de données REDY.
