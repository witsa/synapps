Contrôle l’affichage du titre s’il dépasse la largeur disponible, comme pour les [boutons de menu]({{ site.baseurl }}/concepts/actor-types/input/menu-button.html) :

- **Pas de retour à la ligne** : le titre est coupé net.
- **Retour à la ligne**
- **Retour à la ligne (cassure)**
- **Tronqué** (par défaut) : le titre tient sur une ligne et se termine par « … ».
