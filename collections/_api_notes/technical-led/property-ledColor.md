---
api_type: technical/led
kind: property
name: ledColor
---
Définit la couleur de la LED lorsqu'elle est allumée. La couleur doit être une chaîne de caractères CSS valide (par exemple, `#FF0000`, `rgb(255, 0, 0)`).

{: .pin }

> Les couleurs CSS par mot-clé telles que `red`, `green`, etc., ne sont pas prises en charge.
